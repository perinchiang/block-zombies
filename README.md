# 方块尸潮（暂定名）

方块小人越肩视角打僵尸，手机横屏优先。画面全部由代码生成：没有图片、模型或音频文件。

当前阶段：**M2 第一组 · 霰弹枪与红色恶魔 + 操作与弹道修正，提前引入最小 M3 本地经济**。固定街道搜箱、后台尸潮压力、限时撤离、金币结算和五种限时 buff。红色恶魔守着高价值红箱，可以绕开，也可以交战拿奖励。按 Patrick 希望金币有用途的偏好，出发前加入最小商店，结算后可返回商店；M2 尚未完成，暂不加入 3D 安全屋、改装升级或新武器。

**下一轮设计已收敛，尚未实现：** [环形街区、永久武器升级与试玩计划](docs/PLAYTEST_PLAN.md)。下一步先做可双向绕行、有捷径和危险支路的地图灰盒，同时适配敌人导航、出生点、碰撞与镜头；再做节奏反馈和永久等级。上面的“当前阶段”和下方操作仍描述现有版本。

## 运行

```bash
npm install
npm run dev          # http://localhost:5191 ，同一 Wi-Fi 的手机可用局域网地址打开
```

操作：

- 出发前在商店装备已拥有的武器：步枪免费，霰弹枪花 240 金币永久购买，死亡不丢失。装备选择保存，不增加局内操作按钮。霰弹枪近距离散射击退、6 发弹匣；步枪适合中远距离连射。
- 未购买也可试玩霰弹枪；试玩撤离或死亡都不向钱包入账，也不改变已拥有武器或保存的装备选择。结算后返回商店。
- 正式局只在结算时入账一次：撤离带走本局全部搜刮金币，死亡带走 25%（向下取整）。钱包、已拥有武器和装备选择用 localStorage 保存，仅限当前浏览器、当前设备，不提供云同步；存储读取或写入失败时回退为会话存档，并在界面明确提示。旧版余额每次刷新已清零，无法迁移。
- 红色恶魔在街道左侧守卫红箱；抬手时地面出现红圈，光球飞向固定落点。避开红圈，或从街道右侧绕行。击败它解锁 180 金币红箱并必掉一个 buff。
- 手机横屏：左半屏按住即出现摇杆（移动）；右半屏上下左右拖动可自由俯仰、转向；按住开火键连射，按住时拖动也能上下左右瞄准。
- 电脑：WASD / 方向键移动，点击画面锁定鼠标后用鼠标自由上下左右瞄准，左键或空格开火，Q/E 也能转身。
- 右上角暂停键打开本局物资面板，查看携带金币、已开物资箱与当前 buff；电脑也可按 Esc。暂停期间战斗和所有局内计时停止，继续时清空之前按住的操作。
- 教学只在同一浏览器首次开始前显示；常驻任务文字、距离导航和压力读数已移除，枪声引怪机制保留。
- 准星固定在屏幕中心，相机射线确定瞄准点，子弹从枪口朝该点以 48 m/s 飞行；无自动选敌、准星吸附或追踪。弹丸沿每帧移动线段做三维碰撞，先碰到敌人或场景就命中停止；穿甲 buff 可穿敌人，不能穿场景。
- 靠近物资箱自动开箱、收取金币，移动或开火也不影响；恶魔红箱必须先击败守卫才能打开。90 秒撤离车到站，240 秒离开，站进撤离圈累计 5 秒成功。

调试参数：

- `?skip` 跳过开始面板
- `?auto` 战斗机器人（仅测试射击与生存，不会搜箱或主动撤离）；`?auto=weak` 手残档；`?speed=2` 加速
- `?fps` 显示帧时间和僵尸数量
- `?still` 定格画面（截图用）
- `?shade=flat` 阴影改为纯墨块、不排线（未选用的对比方案 B）
- `?cam=x,y,z&look=x,y,z` 试镜头（相对主角的偏移）

## 定位

- 玩法：方块小人越肩打僵尸，搜物资、权衡贪心和撤离。参考 Call of Mini 的视角和造型路线，主题、角色、地图都是自己的。
- 画风：强线条漫画风。纸白底、统一粗细的黑描边、两三层平涂、黑色硬阴影。不做中国风，不做水墨晕染。
- 技术：Vite + three.js，先验证手机网页版，之后再考虑上 TapTap。

详见 `docs/GAME_DESIGN.md`（目标形态与开发顺序）、`docs/style.md`（画风规则）、`docs/round.md`（当前原型的规则与数值）。
