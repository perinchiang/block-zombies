# 方块尸潮（暂定名）

方块小人越肩视角打僵尸，手机横屏优先。画面全部由代码生成：没有图片、模型或音频文件。

当前工作区已实现 **中央广场试玩版**：40×40 米街区（X/Z 边界 ±20）、四个建筑岛、双向外环与穿过中央广场的十字通路。固定东西入口、地下预警、分阶段交战与喘息、一次性恢复点、中央撤离车，以及两把枪 Lv.1–4 永久升级已接入。东北恶魔守卫红箱，可绕行或交战；敌人使用地图导航绕障。

最新设计方向已转为 **街机杀怪赚金币、Day 主线与独立金币挑战**，暂时搁置搜打撤；这些新模式尚未开发，见 [游戏设计方向](docs/GAME_DESIGN.md) 与 [方向探索和后续试玩计划](docs/PLAYTEST_PLAN.md)。下方操作描述的仍是现有中央广场版，不将设计方案或桌面验证等同于功能已实现、真实手机已验收。

在线预览：https://perinchiang.github.io/block-zombies/ （推送到 main 后由 GitHub Actions 自动部署）

## 运行

```bash
npm install
npm run dev          # http://localhost:5191 ，同一 Wi-Fi 的手机可用局域网地址打开
```

操作：

- 出发前在商店装备已拥有的武器：步枪免费，霰弹枪花 240 金币永久购买，死亡不丢失。装备选择保存，不增加局内操作按钮。霰弹枪近距离散射击退、6 发弹匣；步枪适合中远距离连射。
- 未购买也可试玩霰弹枪；试玩撤离或死亡都不向钱包入账，也不改变已拥有武器或保存的装备选择。结算后返回商店。
- 正式局只在结算时入账一次：撤离带走本局全部搜刮金币，死亡带走 25%（向下取整）。钱包、已拥有武器和装备选择用 localStorage 保存，仅限当前浏览器、当前设备，不提供云同步；存储读取或写入失败时回退为会话存档，并在界面明确提示。存档内容为 v2，沿用 `block-zombies.profile.v1` 键，迁移 v1 钱包/已购/装备并将已有枪设为 Lv.1；未知版本不覆盖。
- 红色恶魔位于东北院落 `(15, -15)`，红箱在 `(15, -17)`；可从西侧或南侧离开院落。抬手时地面出现红圈；命中可打断尚未释放的攻击，成功后有 3 秒打断免疫，已飞出的光球仍需躲避。击败它解锁 180 金币红箱并必掉一个 buff。
- 已拥有的枪可按 60/120/220 金币升到 Lv.2/3/4，提升伤害、弹匣与换弹效率，枪身逐级显示升级条带；死亡保留等级。步枪/霰弹命中分别产生 0.12/0.28 秒硬直，受冷却限制，同次开火对同一目标只施加一次控制。
- 手机横屏：左半屏按住即出现摇杆（移动）；右半屏上下左右拖动可自由俯仰、转向；按住开火键连射，按住时拖动也能上下左右瞄准。
- 电脑：WASD / 方向键移动，点击画面锁定鼠标后用鼠标自由上下左右瞄准，左键或空格开火，Q/E 也能转身。
- 右上角暂停键打开本局物资面板，查看携带金币、已开物资箱与当前 buff；电脑也可按 Esc。暂停期间战斗和所有局内计时停止，继续时清空之前按住的操作。
- 教学只在同一浏览器首次开始前显示；常驻任务文字、距离导航和压力读数已移除，枪声压力仍在后台计算，当前刷怪由阶段导演控制。
- 准星固定在屏幕中心，相机射线确定瞄准点，子弹从枪口朝该点以 48 m/s 飞行；无自动选敌、准星吸附或追踪。弹丸沿每帧移动线段做三维碰撞，先碰到敌人或场景就命中停止；穿甲 buff 可穿敌人，不能穿场景。
- 靠近物资箱自动开箱、收取金币，移动或开火也不影响；恶魔红箱必须先击败守卫才能打开。90 秒撤离车在中央广场 `(2.8, 0)` 到站，240 秒离开；车门旁登车圈中心 `(0.5, 0)`、半径 1.25 米，累计 5 秒成功，离圈暂停。`(-4.5, 3.5)` 的一次性急救补给恢复 1 格血，满血不消耗。

历史试玩：Patrick 曾反馈核心战斗“好玩”，现有版据此增加绕行与金币升级目标。最新方向将收益重心转向击杀金币；本次仅更新文档，现有搜箱、撤离和死亡结算不变。历史反馈不代表真实 iPhone 操作、帧率、发热或新循环已验证。

调试参数：

- `?skip` 跳过开始面板
- `?auto` 战斗机器人（仅测试射击与生存，不会搜箱或主动撤离）；`?auto=weak` 手残档；`?speed=2` 加速
- `?fps` 显示帧时间和僵尸数量
- `?still` 定格画面（截图用）
- `?shade=flat` 阴影改为纯墨块、不排线（未选用的对比方案 B）
- `?cam=x,y,z&look=x,y,z` 试镜头（相对主角的偏移）

触控测试：`node tools/touch-test.mjs`（左手推摇杆 + 右手按住开火拖动，需先开 dev server）。暂停回归：`node tools/pause-test.mjs`（双指暂停、计时冻结、恢复输入与教学不重复）。

M2 回归：`node tools/encounter-test.mjs`（武器、预警与红箱结算）、`node tools/loadout-test.mjs`（手机选枪、重试和弹道暂停）。

本地经济验收预期脚本：`node tools/profile-test.mjs`（钱包/已购/装备持久化、结算仅入账一次、死亡取整、存储失败回退）、`node tools/shop-test.mjs`（240 金币购买、已购装备与刷新恢复、试玩胜负零入账且不改已购/装备、结算返回商店及存储失败提示）。脚本已存在；此处是运行入口，不表示本次文档更新已执行或通过这些测试。新增 `node tools/navigation-test.mjs`、`node tools/central-square-test.mjs`、`node tools/combat-reaction-test.mjs` 覆盖地图导航、中央广场和受击控制。

## 定位

- 目标玩法：方块小人越肩打僵尸、杀怪赚金币、购买升级后挑战更难关卡。参考《Call of Mini: Zombies》的视角、商店与成长，《僵尸危机3》的尸潮与火力，《翻面 FLIPSIDE》的漫画视觉；主题、角色、地图自己设计。
- 画风：强线条漫画风。纸白底、统一粗细的黑描边、两三层平涂、黑色硬阴影。不做中国风，不做水墨晕染。
- 技术：Vite + three.js，先验证手机网页版，之后再考虑上 TapTap。

详见 `docs/GAME_DESIGN.md`（确定方向、暂定建议与待讨论问题）、`docs/style.md`（画风规则）、`docs/round.md`（当前原型的规则与数值）。

参考调研：[《迷你英雄》的刷怪、局内增益、武器与永久成长](docs/CALL_OF_MINI_RESEARCH.md)。含固定版本源码依据、升级与经济公式、与《僵尸危机3》的比较，以及固定入口＋地下出生对本项目的启发；作为历史研究记录保留，当前实现以 `docs/round.md` 为准，不将研究参数视为现行规则。
