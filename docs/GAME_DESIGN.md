# 方块尸潮 · 游戏设计文档

> 版本 v3 · 中央广场试玩版已实现
> 当前工作区规则见 [round.md](round.md)，画风规则见 `style.md`；下一步见 [手机试玩计划](PLAYTEST_PLAN.md)。中央广场、地图导航、阶段导演、恢复点、永久武器等级和受击控制已实现；真实 iPhone 验证仍待完成，不代表线上已部署。

## 1. 一句话

**一本会动的僵尸漫画：每一局是一话。你在纸上的小镇里搜刮、交火、撤离，回到安全屋，把黑白的世界一点点涂上颜色。**

## 2. 定位

| 项目 | 决定 |
|---|---|
| 类型 | 越肩第三人称射击 + 搜打撤（搜刮、交火、撤离） |
| 平台 | 主攻 TapTap；先做手机横屏试玩，电脑网页可玩；发布形态与接入条件待核实 |
| 画风 | 强线条漫画风：纸白、粗黑描边、三档平涂、排线阴影（见 `style.md`） |
| 人物 | 大头方块小人，硬方块四肢，不做蒙皮和手部细节 |
| 一局时长 | 3–5 分钟 |
| 模式 | 单机。异步社交（每日街道 + 排行榜 + 本局漫画分享）代替实时联机 |
| 技术 | Vite + three.js，纯代码生成全部画面和音效 |

参考：视角和造型参考《Call of Mini》；局外成长参考《迷你英雄》；"和朋友比谁撑得久"的感觉来自《僵尸危机3》。机制只借思路，名字、角色、地图都做我们自己的。

## 3. 设计支柱

所有新功能都要先过这四条：

1. **走位与永久成长共同推进。** 环形地图允许绕行、换路和借掩体战斗；局外武器可永久升级，初始吃力的遭遇升级后更好打。基础撤离路线不强制升级，熟练玩家可越级挑战；强化有上限，局内 buff 仍只限时生效。
2. **贪心是核心情绪。** "再多拿一个箱子"和"现在就走"之间的拉扯，是这个游戏最主要的心跳。
3. **允许失败，失败也有收获。** 死了只会丢掉一部分东西，而且照样能拿到一页本局漫画。
4. **只做纯代码擅长的东西。** 靠规则、反馈、方块造型和着色器出效果，回避近景人物表演。

## 4. 当前核心循环

```
商店（购枪、装备、永久升级）
   ↓
进入固定中央广场街区
   ↓
绕行搜箱、交战、拾取限时 buff、选择是否挑战恶魔
   ↓
90 秒中央车到站 → 现在撤离，还是再搜一箱？
   ↓
撤离带走全部金币 / 死亡保留 25%（向下取整）
   ↓
返回商店，升级后再试
```

未购霰弹试玩固定 Lv.1，无金币入账。未来再考虑实体安全屋、随机地图、漫画结算、幸存者与上色。

## 5. 一局的流程（搜打撤）

### 5.1 阶段

| 时间 | 阶段 | 发生什么 |
|---|---|---|
| 0:00 | 进场 | 玩家 `(0,5)`，慢速目标 `(0,-10)`；中央通路第一箱 `(0,-5)` |
| 0–20 秒 | 初次交战 | 西入口，4.2 秒间隔 / 活怪上限 7 |
| 20–45 秒 | 加压 | 西入口，2.1 秒 / 上限 12 |
| 45–60 秒 | 喘息 | 停止入口刷新，现存敌人继续追击 |
| 60–90 秒 | 换向交战 | 东入口，2.5 秒 / 上限 14，跑者概率 12% |
| 90–240 秒 | 撤离窗口 | 中央车到站；每 35 秒一轮，西/东交替，25 秒交战 + 10 秒停止入口刷新 |
| 240 秒后 | 末班车离开 | 入口刷新间隔乘 0.55，新生敌人速度乘 1.6；不自动胜利 |

这些数值已实现，仍待手机调优。90 秒后间隔由 2.2 秒逐轮减 0.15 秒、最低 1.3 秒，上限由 15 逐轮加 1、最高 22，跑者概率 18%。地下事件独立于入口喘息。

### 5.2 尸潮压力

后台仍计算时间与枪声压力，不显示压力指数。当前刷怪由阶段导演控制，不根据压力值增加频率或精英；枪声引怪的进一步联动仍需后续设计。固定入口为西 `(-19,-10)`、东 `(19,10)`，地下出生只能选预设区域，单个预警持续 2.2 秒；结束时玩家距点小于 2.2 米则取消出生。

### 5.3 物资箱

- **靠近自动开箱、收取金币**，移动和开火时也可拾取，不设置搜索等待或开箱进度。风险来自接近物资时的走位与交战。
- 当前六普通箱值 30/42/54/66/78/90 金币，恶魔红箱值 180，共 540。零件、手雷、幸存者线索和加固箱是未来候选。
- 红箱必须先击败守卫恶魔，再靠近自动打开。另有 `(-4.5,3.5)` 一次性恢复点，恢复 1 格血，满血不消耗。

### 5.4 撤离

- 中央广场车中心 `(2.8,0)`，90 秒出现、240 秒离开；西侧车门登车圈中心 `(0.5,0)`，半径 1.25 米，车辆到站后有实体碰撞。
- 站进圈里坚持 **5 秒**才算撤离成功。这段时间里尸潮会往圈里涌，所以撤离本身就是最后一场硬仗。
- 撤离可以中断：离开圈子，倒计时就暂停。

### 5.5 失败的代价

以下表格含远期目标；当前仅实现金币结算，零件、幸存者、本局漫画尚未实现。

| 结局 | 金币 | 改装零件 | 幸存者 | 本局漫画 |
|---|---|---|---|---|
| 撤离成功 | 全部带走 | 全部带走 | 全部带走 | 有 |
| 死亡 | 带走 25% | 全部丢失 | 本局救的人丢失 | 有，标题改成"未能撤离" |

**带进去的装备永远不会丢。** 我们不做"死了掉枪"，那样惩罚太重，不符合允许失败的原则。

## 6. 局内限时 buff

### 6.1 规则

- 僵尸死亡时有小概率掉落 buff 球，精英怪必掉一个。
- 每个 buff **持续 8 秒**。同类型再捡到会刷新时间，不会叠加数值。不同类型可以同时生效，最多两个。
- buff 球在地上只留 6 秒，不去捡就消失，逼玩家走位冒险。
- 生效时屏幕边缘出现对应的漫画效果线，界面上显示倒计时。
- **buff 永远不会变成永久成长。**

### 6.2 第一批

| buff | 效果 | 用途 |
|---|---|---|
| 狂热 | 射速 +60%，不用换弹 | 清掉眼前一大群 |
| 穿甲 | 子弹穿透路径上的敌人，不能穿场景 | 对付一条直线上的尸潮、防暴盾 |
| 爆裂 | 命中时小范围爆炸 | 清理扎堆的僵尸 |
| 疾走 | 移速 +40%，撞开普通僵尸 | 突围、冲向撤离点 |
| 墨盾 | 挡住下一次扑咬 | 犯错时的保险 |

### 6.3 视觉

buff 是画风里**唯一新增的强调色**：青蓝 `#4f8fb0`，只给 buff 球和生效中的 buff 用。buff 球做成漫画对话气泡的形状，里面画一个符号（闪电、箭头、星形……）。远远看去，玩家一眼就能分清"红色是危险，青蓝是好东西"。

## 7. 敌人

全部用方块小人改出不同轮廓，靠剪影一眼就能分清。每一种都在逼你换一种打法：

| 敌人 | 外形 | 行为 | 克制方法 |
|---|---|---|---|
| 普通 | 绿皮，双臂前伸 | 慢，成群 | 什么都行 |
| 跑者 | 身体前倾 | 快，会扑 | 霰弹击退、提前预判 |
| 防暴盾 | 手持一块方板 | 正面挡子弹，推着你走 | 绕到侧面、手雷、穿甲 |
| 胖子 | 宽方块 | 死后炸出一摊毒墨，踩上去会掉血 | 在远处解决、狙击 |
| 红色恶魔 | 全身红，体型大 | 精英怪 / Boss。扔出黄色光球，落点先出现红圈，爆炸造成范围伤害 | 走位躲红圈，用爆发武器打 |

- 当前仅普通怪、跑者和一只固定恶魔已实现。恶魔在东北 `(15,-15)`，红箱 `(15,-17)`，院落西、南侧可离开，击败解锁红箱并必掉 buff。未释放攻击可被命中打断，成功后 3 秒免疫打断，已飞出光球仍有效。
- 普通敌人步枪/霰弹硬直为 0.12/0.28 秒，有控制冷却；同次扳机对同一目标最多一次控制，散弹和爆裂不能重复叠加。
- 后续可以再加：会爬墙的、会尖叫召集同伴的。前提是每加一种，都必须带来一种新的打法。

## 8. 武器与装备

### 8.1 装备栏

目标形态：一把主武器 + 一把副武器（手枪，弹药无限）+ 一个道具。当前每局只带一把主武器：免费步枪，或花 240 金币永久购买的霰弹枪；死亡不丢枪。出发前在商店装备已拥有的枪并保存选择，结算后返回商店。未购买霰弹枪也可试玩，但试玩不改变已拥有武器或保存的装备选择，撤离和死亡均不向钱包入账。

### 8.2 主武器（第一批）

每把枪都**换一种打法**，不是同一把枪数字更大：

| 武器 | 定位 |
|---|---|
| 步枪 | 均衡，就是现在原型里那把 |
| 冲锋枪 | 射速高、射程短，适合边跑边打 |
| 霰弹枪 | 扇形散射，击退很强，专门解决贴脸 |
| 狙击枪 | 单发高伤，子弹穿透 |
| 机枪 | 弹匣很大，开火时移动变慢，适合守撤离圈 |

### 8.3 永久武器升级（近期）与改装（远期）

当前每把已拥有武器提供 Lv.1–4 的永久等级，金币购买、死亡保留；提升伤害、弹匣与换弹效率，让原本吃力的遭遇更好打。等级在商店提升，局内不弹升级三选一；满级封顶，同一地图不按玩家等级自动涨敌人血量。

升级费用 60/120/220，伤害倍率 1/1.5/1.75/2，弹匣步枪 24/27/30/33、霰弹 6/7/8/9，换弹倍率 1/0.95/0.9/0.85；详细叠加和迁移见 [试玩计划 §5](PLAYTEST_PLAN.md#5-永久武器升级与经济)。这些是当前实现，平衡仍待调优；综合强度要按实际输出与生存收益测量。

模型已逐级显示升级条带。弹匣、枪口、瞄具三槽改装保留为远期候选，第一轮不与等级系统并做。

### 8.4 道具

| 道具 | 效果 |
|---|---|
| 手雷 | 抛物线投掷，落地爆炸。局内从箱子里补充 |
| 地雷 | 提前布在路上 |
| 喷气背包 | 短距离跳跃，从尸群头上越过去，有冷却时间 |
| 诱饵 | 扔出去以后，僵尸会被吸引过去几秒 |

## 9. 瞄准与镜头

Patrick 试玩后要求自由瞄准和实体弹道，取消自动选敌与吸附。

1. **自由上下左右瞄准**：鼠标和右侧触控拖动都控制镜头俯仰、转向；按住开火键拖动也能上下左右瞄准。
2. **固定中心准星**：从相机屏幕中心发出射线确定瞄准点，弹丸从枪口朝该点发射；枪口前的障碍仍然挡弹。
3. **完全手动瞄准**：没有自动选敌、准星吸附或贴脸优先；弹丸发射后不追踪，移动目标需要提前量。
4. **有限速度与三维碰撞**：弹丸以 48 m/s 飞行，每帧沿移动线段进行三维扫掠，命中最先遇到的敌人或场景后停止。霰弹分别计算每颗弹丸。
5. **穿甲例外**：穿甲 buff 允许弹丸继续穿过敌人，但不能穿过场景，也不改变飞行方向追敌。
6. **背后提醒**：背后有僵尸靠近时，屏幕边缘出现红色墨迹箭头。不提供独立的快速转身按钮。
7. **战斗画面保持简洁**：不常驻搜刮说明、撤离车到站文字、物资距离、携带数量或开箱统计。自动开箱不显示搜索进度，保留撤离进度。携带物资与开箱记录放进暂停面板；教学首次出现后不再自动重复。暂停时战斗和所有局内计时停止。

## 10. 安全屋

当前局外界面采用出发前商店与结算后返回商店，已有钱包、购枪、装备、试玩和永久武器等级。实体安全屋、新武器和多槽改装后置。

目标安全屋是局外的主界面，也是一个**实体场景**：一间用木板封住的小加油站。

- **枪架**：买过的枪挂在墙上，点一下就能装备。
- **改装台**：花金币和零件改枪。
- **幸存者**：在关卡里救出来（以后会有护送目标），带回来就住进安全屋。每个人提供一项服务，比如：
  - 修车的老头：解锁改装台
  - 小孩：每天出门前送一个补给
  - 无线电员：解锁每日街道
- **地图墙**：贴着小镇地图，已经解锁的街区会被涂上颜色。

### 10.1 给世界上色

整个世界一开始只有纸白、墨黑和暖灰。每解锁一张地图、每救回一个幸存者，对应的区域和安全屋就被**涂上一种颜色**。玩家看颜色就知道自己的进度，不用看数字。红色永远只留给危险，不参与上色。

## 11. 地图与种子

- **当前为手工中央广场街区**：40×40 米、X/Z 边界 ±20，四个 6×6 建筑岛中心 `(-10,-9)`、`(10,-9)`、`(-10,9)`、`(10,9)`；双向外环与十字通路穿过中央广场，东北恶魔院落西、南开放。
- 导航、出生点、碰撞、镜头与撤离位置已适配；手机上绕行和遮挡仍需验证。固定位置与验收见 [试玩计划](PLAYTEST_PLAN.md)。
- 先用固定地图比较走位和升级收益。路段模块、随机种子、天气时段与 3 张地图解锁为远期候选，不作为邀请首批玩家的前置条件。
- 未来同一种子应生成相同街区，才可支持分享与比分。

### 11.1 每日街道

- 每天全世界的玩家用同一个种子，再加一个当天的变化，比如"今天全是跑者""今天只能用霰弹枪""今天有浓雾"。
- 当天的成绩上排行榜。这就是我们的异步社交：不用联机，也能和朋友比谁撑得久、带出来的东西多。

### 11.2 夜晚

夜晚关卡把画面**反过来**：黑底、白线，玩家手里一圈手电筒光。僵尸的白色轮廓从黑暗里冒出来。技术上只是换一组颜色再加一个光圈，但看起来像一个全新的游戏。

## 12. 本局漫画

每一局结束，不管撤离成功还是死了，都会自动生成一页漫画。

- **自动截取高光**：第一次被包围、buff 清掉一大群、打倒红色恶魔、差一点被咬死、撤离前最后一秒，或者死亡的那一刻。
- **排成一页**：4–6 格，配上"砰！""咔嚓！"之类的拟声字，再加一句自动生成的旁白，比如"第 147 秒，他以为背后是安全的。"
- **可以保存、可以分享。** 好看的一页会被玩家截图发出去，这是我们最便宜的宣传。
- 安全屋里有一面墙，贴着历史上最精彩的几页。

## 13. 经济与变现

### 13.1 货币

| 货币 | 来源 | 用途 |
|---|---|---|
| 金币 | 撤离带出、箱子 | 买枪、买道具、改装 |
| 零件 | 撤离带出 | 改装（死亡时全部丢失） |

暂时不做第二种高级货币（钻石）。等真的要接广告或内购时再决定。

### 13.2 当前最小本地经济（提前引入的 M3 子集）

搜刮收益已可用于购买霰弹枪和两把枪的 Lv.1–4 永久升级。当前不包含 3D 安全屋、多槽改装、新武器、零件或广告。

- 步枪免费拥有；霰弹枪 240 金币，余额足够才可购买，扣款一次并永久拥有，死亡不丢失，已购不重复扣款。装备已拥有的武器时保存选择。
- 正式局仅在结算时向钱包入账一次：撤离获得本局全部搜刮金币，死亡获得 25%（向下取整）。重复查看结算或返回商店不会再次入账。
- 未购买也可试玩霰弹枪；试玩撤离和死亡入账均为 0，不改变已拥有武器或保存的装备选择。出发前进入商店，结算后可返回商店。
- 钱包、已拥有武器、装备选择与永久等级通过 localStorage 保存，仅限当前浏览器、当前设备；不提供云同步。读取或写入失败时使用会话存档，界面明确提示无法持久保存、刷新可能丢失进度。
- 存档内容为 v2，沿用 `block-zombies.profile.v1` 键；v1 迁移保留余额、已购与装备，已有枪默认 Lv.1。未知版本不覆盖。

验收预期测试路径：`tools/profile-test.mjs`（持久化恢复、成功全额/死亡取整、单次入账、存储失败回退）和 `tools/shop-test.mjs`（免费步枪、240 金币购买与余额不足/防重复扣款、死亡不丢枪、装备保存、试玩胜负零入账且不改已购/装备、返回商店与失败提示）。具体命令见 `round.md`；脚本已存在，列出路径不代表本次文档同步已运行或全部通过。

### 13.3 原则

- **免费也能慢慢刷到所有东西。** 广告只用来加速，不卖胜负。
- **不做抽卡出枪。** 枪只能买，不靠运气。
- 激励广告只放在玩家自己愿意点的地方：
  - 撤离成功后，看广告金币翻倍
  - 死亡时，看广告原地复活一次（每局限一次）
  - 安全屋每天一个免费补给箱

### 13.4 待核实

TapTap Maker 有现成的广告接入，但广告分成、版号要求、H5 包能不能接广告，**都还没有核实**。在做第 6 阶段之前要先查清楚。

## 14. 联机

- **现在不做实时联机。** 服务器、匹配、几十只僵尸的同步，成本比目前整个游戏还高。
- 先用**每日街道 + 排行榜 + 本局漫画分享**提供社交感。
- 如果以后数据证明大家确实想和朋友一起打，再考虑双人合作。到那时 TapTap Maker 自带的多人联机支持是一个选项，但它用 Lua 引擎，意味着要重写。

## 15. 我们故意不做的

- **局内永久加点、无上限的数值膨胀**。局外有上限的武器永久等级已纳入近期；局内 buff 仍不永久化。
- **"幸存者"式自动开火和升级三选一**：同质化太严重，也违背"靠走位"的原则。
- **剧情过场、近景对话、人物表演**：会碰到人物动作这个老坑。
- **开放世界**：一条街区就够了。
- **抽卡**。
- **死亡掉落带进去的装备**：惩罚太重。
