# 画风规则（第一天样张）

## 一句话
纸上画出来的漫画：奶白纸底，粗黑描边，平涂两三层，阴影是墨。

## 颜色（`src/render/palette.js`）
- 纸白 `#efe6d1`、墨黑 `#1d1b21` 撑起整个画面。
- 环境只用沙色、石灰、浅沥青几种低饱和暖灰。
- 每个强调色只有一个用途：
  - 主角黄 `#e0a43a`：只给主角，方便玩家一眼找到自己。
  - 僵尸绿 `#9fb48c`：只给僵尸皮肤。
  - 血红 `#c4322b`：只给伤害、血迹和危险（含血量、开火键）。
  - 青蓝 `#4f8fb0`（计划中）：只给局内限时 buff，见 `GAME_DESIGN.md` 第 6 节。
  - 火橙 `#f2761b`：只给枪火——枪口火光外圈、曳光弹、命中爆点。浅黄打在纸白地面上看不见，所以曳光不用浅色。
  - 金 `#f2b429`：只给金币和奖励（掉落金币、飞回的金币、奖励数字、HUD 金币图标）。
- 武器用冷色中性灰：枪身 `#73859a`、握把弹匣 `#474e5a`、枪管 `#c3c9cc`，木件 `#8f5a36`。**枪上不用墨黑**：墨黑是描边色，整把枪会糊成一团。
- 远处靠雾退成纸白，线条也一起变淡。

## 着色（`src/render/toon.js`）
- 基于 Lambert，按受光强弱分三档：亮面 = 原色，中间面 = 原色 × 0.8，暗面 = 原色混墨。
- 暗面加斜向排线（屏幕空间，粗细随设备像素比）。**2026-11-14 Patrick 选定此方案（A）**。
- `?shade=flat` 纯墨块方案（B）只保留作对比，不作为默认。
- 阴影贴图交给三档量化，所以边缘是硬的。

## 描边（`src/render/inkline.js`）
- 屏幕空间后处理：轮廓来自“深度倒数”的二阶差分（平面上为 0，不会在斜地面出假线），折痕来自法线差。
- 线宽按 CSS 像素指定（手机矮屏 1.8，其余 2.2），近粗远细，带轻微的笔压起伏。
- 叠一层纸面颗粒和很轻的暗角。
- 太细小的东西不描边：曳光弹、弹头、血块、弹壳放在 `NO_INK_LAYER`，只画颜色。7 厘米的方块描完边就只剩边，红的黄的都会变成黑点。

## 人物（`src/actor/`）
- 大头方块小人。四肢是硬方块，从关节转动，**不做蒙皮、不做手指、不做 IK**，僵硬就是风格。
- 脸和衣服图案用 canvas 画几笔墨，贴在方块正面。
- 僵尸：双臂前伸、身体前倾、歪头，走路只摆腿。
- 主角：枪握在右前臂外侧，从右肩后能看到枪身和火光。棕发、纸白头带、帆布背包和铺盖卷——玩家大部分时间看的是背面，背面不能是一块黑。
- 枪由 `src/actor/guns.js` 里的零件表生成，同一张表同时产出 3D 模型和 HUD／商店里的侧面图标。每把枪先靠轮廓区分（步枪细长、霰弹枪粗短双管），再靠材质（冷金属、暖木头）。

## 镜头
- 越肩：主角右后上方，主角在画面左下，路和尸潮在中间。
- 手机横屏（844×390）为基准截图尺寸，竖屏时提示横过来。
- 贴墙：背后有墙时镜头沿机位滑向主角眼睛高度，最近处是第一人称，不会缩进身体里；靠近时主角先半透明再隐藏。墙在右侧时自动换到左肩，右侧空出来再换回。

## 还没验证
- 真机帧率：描边需要多画一遍场景，手机上的性能还没测。
- 远处小物体的描边是否太乱，要等场景更密时再看。
