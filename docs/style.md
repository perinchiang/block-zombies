# 画风规则（彩色漫画版）

## 一句话
上色的漫画格子：粗墨线勾轮廓，平涂上色，暗面偏冷紫；暖色天空配冷色街道。

2026-11-17 Patrick 认为旧的“纸上铅笔稿”方案太像灰盒原型，选定彩色漫画方向。旧版（纸白底＋斜线排线）见 git 历史 `59cc82a`。

## 颜色（`src/render/palette.js`）
- **天空暖、街道冷**：天顶深蓝 `#3d6fa8`，过渡橙 `#e7956a`，地平线奶黄 `#f6d6a2`；雾取地平线色，远景楼群退成雾里的淡紫。
- 路面是冷蓝灰沥青 `#6c7385`，中央广场是暖赤陶方砖，人行道沙色石板。角色和强调色都压在与自己反差大的底上。
- 四栋楼各一个颜色（芥末黄、海绿、灰粉、灰蓝）＋深紫灰墙脚，靠颜色也能认路。
- 强调色仍然一色一用：
  - 主角黄 `#f0b234`：只给主角夹克。
  - 僵尸绿 `#8cbf5b`：只给僵尸皮肤；僵尸衣服从 `ZOMBIE_CLOTHES` 八套褪色衣裤里取。
  - 血红 `#c4322b`：伤害、血迹、危险。
  - 火橙 `#f2761b`：枪火。金 `#f2b429`：金币与奖励。青蓝 `#4f8fb0`：buff。
- 武器仍用冷灰金属与木色，**枪上不用墨黑**。
- UI 卡片保留纸白 `#efe6d1`＋墨黑描边，像贴在画面上的漫画对白框。

## 着色（`src/render/toon.js`）
- Lambert 三档：亮面 = 原色；中间面 = 原色 × 0.84 再略偏冷紫；暗面 = 原色 × 0.62 混 30% 冷紫 `#3b3360`。
- **物体表面不印任何屏幕空间图案**（网点、排线都不要）：图案按屏幕像素固定，墙在动、图案不动，像隔着一层带点的玻璃看，人一走就觉得斑点在跟着动。2026-11-17 Patrick 反馈后全部去掉，暗面只用平涂色块。
- 天空（`src/render/sky.js`）：地平线到橙色是实色渐变，橙到蓝用网点过渡，像印刷品。天空的网点按方位角/仰角钉在天上，跟着视角转，不在屏幕上滑；格子数取整，方位角 ±π 处没有接缝。
- `?shade=flat` 仍可看纯墨块暗面作对比。

## 描边（`src/render/inkline.js`）
- 屏幕空间后处理：轮廓来自深度倒数的二阶差分，折痕来自法线差；近粗远细。
- 笔压抖动减到 ±8%，大块取样，避免小零件上的短边断成乱线。
- **细节画进贴图，不做成小方块**：裂缝、砖块、地砖缝、窗框、背包盖和口袋都是 canvas 上的细线（`src/render/textures.js`），只有大轮廓交给墨线。小方块堆在一起描边就会乱。
- 太细小的东西不描边：曳光、弹壳、血块、电线、地面贴花放在 `NO_INK_LAYER`。
- 枪械保留轮廓，但线宽为场景的 50%。`inkWeight` 顶点属性写入法线图 alpha，普通物体默认 1；不另加绘制遍数，避免手机尺寸下枪管被粗线吞掉。

## 场景（`src/world/arena.js`）
- 碰撞、挡弹和寻路仍是原中央广场布局，一点不变。
- **任何两个表面不能共面**：共面的面会深度冲突（z-fighting），镜头一动就闪。出入口柱子画成 0.74 m 见方、比 0.5 m 的墙厚（碰撞体仍是 0.5 m）；楼顶檐口比楼顶高 4 cm；东西两侧压顶比南北高 2 cm。新加物件贴墙时要么凸出、要么缩进，别正好齐平。
- 门：门框和门板都凸出墙脚（墙脚 0.55 m 高、外凸 4 cm），否则会被深紫墙脚盖住下半截。门板是画出来的木门（玻璃窗、凹板、把手、踢脚板），四栋楼各一个颜色。
- 雨棚挂在门上方墙面，内沿高、外沿往下斜（`rotation.x = side * 0.38`）。
- 招牌、雨棚、海报、楼顶水塔、墙外路灯、电线杆、报废汽车、远景楼群、地面井盖和污渍都放在 `decor` 组：只看不碰，子弹和寻路都不管它。
- 贴图按“米”铺 UV（`worldUV`、`planeUV`），大墙小墙纹理密度一致，不拉伸。

## 人物（`src/actor/`）
- 大头方块小人，硬关节，不蒙皮、不做手指和 IK。
- 主角头宽 0.62，棕发颜色在正、侧、背面统一。侧发和后发直接画在头部贴图上；头顶只留一个发块，白头带宽 0.68，与头部每侧相隔 3 cm，不与发块共面。
- 去掉背包和铺盖卷，背面保留完整黄夹克、小布章和深色下摆；加方块手套和短靴。
- 枪独立挂在持枪组上，左右手分别固定到每把枪的握把、护木位置；两段硬袖子连接肩、预设肘点、手腕，不使用蒙皮或 IK 求解器。
- 枪承担瞄准俯仰和主要后坐力，躯干只跟随 18% 的瞄准角，头部再跟随一小部分。升级到最高级、最大仰角时枪也必须避开头带。
- 步枪强调粗亮枪管与机匣，霰弹枪强调宽双管和木护手。HUD 与商店图标继续使用相同的武器部件数据。

## 镜头
- 越肩视角，主角在画面左下；手机横屏 844×390 为基准截图尺寸。贴墙规则不变。

## 还没验证
- 真机帧率：场景装饰增加了不少绘制调用（远景约 40 栋、路灯、电线杆、汽车），描边本来就要多画一遍，手机性能需要实测。真机吃力时先合并远景几何或去掉楼顶杂物。
- 天空网点在低端屏上会不会闪。
