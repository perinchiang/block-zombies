# 中央广场版：当前实现与下一次手机试玩

> 状态：中央广场地图、导航、阶段导演、恢复点、永久武器等级和受击控制已在当前工作区实现。本文记录交付状态与下一次验证；精确规则见 [round.md](round.md)。这不是线上部署或真实 iPhone 验收记录。
>
> Patrick 的目标仍是尽快观察玩家是否愿意玩、重开和返回。主攻 TapTap，先交付手机横屏试玩；发布形态与商业接入条件另行核实。

## 1. 当前体验

搜箱 → 绕建筑交战、换路线 → 选择挑战东北恶魔或返回中央广场 → 撤离/死亡结算 → 用金币升级已有枪 → 再试。基础路线不强制升级，恶魔是可选挑战；是否足够好玩、初始装备是否合理，必须由手机试玩判断。

地图已采用四个建筑岛围绕中央广场的布局，取代早期“一个中央建筑组、南侧捷径”的草案。外环可双向走，东西和南北通路穿过广场，允许中途换路。

## 3. 中央广场与固定位置

坐标为 `(x,z)`，负 Z 为北。建筑岛中心 `(-10,-9)`、`(10,-9)`、`(-10,9)`、`(10,9)`；西南建筑有修车铺卷帘门地标。玩家从 `(0,5)` 出发。

- 西入口 `(-19,-10)`，东入口 `(19,10)`；入口距玩家大于 3 米、附近不拥堵且未达上限才刷新。
- 地下区域 `(-16,1)`、`(16,-1)`、`(0,-15)`、`(0,15)`。从附近合适点选一个，碎土和红圈预警 2.2 秒；结束时玩家距点小于 2.2 米则取消。任一时刻最多一个预警。
- 普通箱 `(0,-5)`、`(-16,-4)`、`(-16,15)`、`(0,16)`、`(16,5)`、`(0,-16)`，分别值 30/42/54/66/78/90 金币。
- 东北恶魔 `(15,-15)`，红箱 `(15,-17)` 值 180；院落西、南两侧开放，不必为基础撤离挑战恶魔。
- 急救补给 `(-4.5,3.5)`，不足 5 格血时靠近恢复 1 格，一局一次，满血不消耗。
- 撤离车中心 `(2.8,0)`，西侧车门登车圈中心 `(0.5,0)`、半径 1.25 米。车未到时有停车标记。

原定环路 30–45 秒、院落额外 10–15 秒只是早期目标，并非当前实测结论；下一次试玩记录实际用时。

## 4. 当前节奏

| 时间 | 实现 |
|---|---|
| 0–20 秒 | 西入口，4.2 秒间隔，上限 7，无跑者 |
| 20–45 秒 | 西入口，2.1 秒间隔，上限 12，无跑者 |
| 45–60 秒 | 停止入口刷新，现存敌人继续追击 |
| 60–90 秒 | 东入口，2.5 秒间隔，上限 14，跑者概率 12% |
| 90 秒后 | 每轮 35 秒，西/东交替；25 秒交战、10 秒停止入口刷新；跑者概率 18% |
| 90–240 秒 | 中央车开放；圈内累计 5 秒，离圈暂停、受伤不清空 |
| 240 秒后 | 车离开，入口间隔乘 0.55，新生敌人速度乘 1.6，不自动胜利 |

90 秒后轮次 n 从 0 起，刷新间隔 `max(1.3,2.2−0.15n)` 秒，上限 `min(22,15+n)`；上限包含活着的恶魔。地下事件独立运行：首次 48 秒尝试，此后 90 秒前每 27 秒、之后每 23 秒尝试，因此喘息段并非绝对无新增敌人。枪声压力仍计算，但当前导演不按该数值调整刷怪。

步枪/霰弹对普通敌人分别施加 0.12/0.28 秒硬直，受冷却限制；同次开火对同一目标最多一次控制，避免散弹和爆裂重复打断。恶魔未释放的攻击可以被命中打断，随后 3 秒免疫打断，已发出的光球仍然有效。

## 5. 永久武器升级与经济

| 等级 | 弹丸伤害倍率 | 弹匣：步枪 / 霰弹 | 换弹时间倍率 | 升至本级费用 |
|---|---:|---:|---:|---:|
| Lv.1 | 1.00 | 24 / 6 | 1.00 | 基础级；霰弹仍需 240 买枪 |
| Lv.2 | 1.50 | 27 / 7 | 0.95 | 60 |
| Lv.3 | 1.75 | 30 / 8 | 0.90 | 120 |
| Lv.4 | 2.00 | 33 / 9 | 0.85 | 220 |

这些参数已实现，平衡仍待调优。射速、散射、射程和控制不升级；霰弹远距伤害同乘等级倍率，爆裂额外伤害仍为 1，一次扳机最多一次爆炸。等级在开局锁定，弹丸保留发射时配置；枪身条带显示等级变化。

普通怪/跑者/恶魔分别 3/2/36 血，无 buff 步枪 Lv.1–4 理论命中数依次为普通怪 3/2/2/2、跑者 2/2/2/1、恶魔 36/24/21/18。该对照不包含落空、换弹与走位，不承诺每一级对每种怪都少打一枪。

六普通箱加红箱共 540；正式局撤离全带走，死亡保留 25% 向下取整，仅结算入账一次。每把枪升级总价 400，买齐升满共 1,040；这只支撑短期试玩，不能证明长期留存。

存档内容 v2 沿用 `block-zombies.profile.v1` 键，迁移保留 v1 钱包/已购/装备并赋已有枪 Lv.1；未知版本不覆盖，存储失败使用会话存档并提示。未购霰弹试玩固定 Lv.1、无金币入账、不能升级、不改变已购和保存装备。死亡不丢枪、不降级。

## 6. 下一次真实手机试玩

先固定测试版本，记录手机型号、系统、浏览器和横屏尺寸；桌面手机尺寸模拟与机器人结果仅作为技术回归，不能证明真实 iPhone 帧率、触控或乐趣。

1. 用 Lv.1 步枪从首次教学开始，观察能否自行移动、瞄准、按住开火拖动和拿第一箱。
2. 正反绕外环各两圈，通过东西、南北十字通路改道；检查建筑四角、贴墙开火、敌人追击与镜头避障。
3. 看懂入口切换和地下预警，主动走上预警验证安全取消；观察喘息是否足够搜箱和恢复。
4. 走东北院落两侧出口；对比恶魔未释放/已释放攻击的命中结果及 3 秒打断免疫，检查是否容易误解。
5. 90 秒返回中央车，验证车门可达、半径 1.25 米的登车圈易用、离圈保留进度、暂停冻结及 240 秒离站。
6. 结算后升级并在相同路线比较 Lv.1/Lv.2，检查模型条带、商店数值、刷新恢复；另测霰弹试玩与正式局隔离。
7. 连续两三局记录帧率波动、发热、误触、退出点和是否主动重开。根据反馈优先修阻断，再调数值或补设置。

自动验证入口见 [round.md](round.md#验证)：地图/导航、中央广场、受击控制、弹道、撤离、buff、暂停、商店和存档脚本已存在。本次文档同步不声明这些脚本全部通过。

## 7. 反馈与范围

第一轮先用观察记录：版本、局次、武器等级、第一箱/首次受伤/恶魔交战/撤离/结算时间、死亡位置、升级和重开，以及玩家原话。事件日志与后端收集尚属未来方案；若主动上传，需说明内容与用途，不收集原始触控轨迹或无关个人信息。

手机验证能自行开始、搜箱、辨认危险、撤离并结算，且无严重碰撞、输入或性能阻断后，邀请约 5–10 位目标玩家，观察退出、重开与隔天自主返回。少量样本或口头喜欢不等于留存、付费意愿。

不为首批试玩增加新枪新怪、投掷道具、多地图、随机生成、完整安全屋、幸存者、漫画分享、排行榜、账号、云存档或广告支付 SDK。灵敏度/音量、表现反馈和画质设置按手机结果安排；完整远期设计见 [GAME_DESIGN.md](GAME_DESIGN.md)。[Call of Mini 研究](CALL_OF_MINI_RESEARCH.md) 保留为历史参考，不作为当前数值或完成状态依据。
