# 下一轮试玩设计：环形街区与永久武器升级

> 状态：已确认方向，待实现。本文是下一轮的范围与实施顺序，不是当前版本说明。当前已实现规则以 [round.md](round.md) 为准；本轮安排优先于 [GAME_DESIGN.md](GAME_DESIGN.md) 的远期 M1–M6 顺序。
>
> Patrick 的目标：尽快验证真实玩家愿意玩、返回，以及后续付费或自愿看广告的可能性。现阶段主攻 TapTap，先交付手机横屏试玩；发布形态与商业接入条件另行核实。

## 1. 这次要交付的体验

玩家进入能持续绕行的街区，靠走位、掩体与换路线搜集补给；可以选择提早撤离，也可以挑战恶魔抢红箱。失败保留部分金币，回商店升级现有武器，再来挑战之前难打的区域。

两条明确决定：

- 地图从直街改为**闭合主环路 + 中央捷径 + 可绕出的危险支路**。玩家可以顺时针、逆时针、绕障碍和改变路线，不能只是沿单一圆圈无限跑。
- 增加**局外永久武器等级**，金币购买、死亡保留。允许“初始武器打某些遭遇吃力，升级后更容易打过”。基础路线仍让初始装备有合理的成功机会，高风险奖励为成长提供目标。

第一次试玩的完整过程是：看懂操作 → 拿到第一箱 → 遇到需要绕行的敌群 → 选择恶魔或撤离 → 结算 → 购买可感知的升级 → 再次尝试。

## 3. 环形街区

### 3.1 布局草案

俯视示意仅表示连通关系，不代表尺寸、朝向或最终坐标：

```text
       西北 ───── 北侧交战区 ───── 东北入口 A ───┐
        │                            │        │
        │      [中央建筑，非通路]      │     恶魔院落
        │                            │     / 红箱
    西侧修车铺 ── 中央广场 / 捷径 ── 东侧出口 B ──┘
        │                            │
        │                            │
       西南 ───── 出发 / 撤离广场 ───── 东南
```

主环为“西北 → 北侧 → 东北 A → 东侧 B → 东南 → 出发广场 → 西南 → 修车铺 → 西北”，可双向通行。捷径为“修车铺 ↔ 中央广场 ↔ 东侧 B”，从中央建筑南侧经过，不穿建筑。危险支路为“A ↔ 恶魔院落 ↔ B”，与主环 A–B 段并联，绕过恶魔的主路保持畅通。所有连接应在灰盒中明确画出。

### 3.2 地图规则

- 一个中央建筑组组织主环，主环四侧可双向通行。至少两处连接形成换路机会，遮挡物旁留出玩家和追兵的通行宽度。
- 主环纯移动一圈目标约 30–45 秒，危险院落额外绕行约 10–15 秒；均为灰盒调试目标，按当前 3.4 m/s 移速与手机视野实测，不据此预先固定尺寸。
- 两名普通敌人并排不能轻易堵死整条主路；少量窄段只作短距离选择，出口在进入前能识别，不藏强制死胡同。
- 车辆和路障提供拐角、换弹遮挡与聚怪空间。正面、侧面、子弹碰撞与移动边界一致；不靠不可见墙或穿模型限制路线。
- 第一普通箱放在可见且安全的入口附近，其余普通箱分布在主环不同区段。暂保留六个普通箱与一个红箱，不先增加总奖励。
- 恶魔继续是可选挑战，院落有两条可走的出路；从基础路线绕行不会被迫触发恶魔。明确标出脱战边界与红箱位置。
- 出发/撤离广场兼作地标，保证从主环两侧都能抵达，登车区贴合车门。车未到时该位置也有可识别的停车标记。
- 一个固定一次性恢复点放在需要少量绕行、又不进入恶魔院落的位置；基础提案为恢复 1 格血，不超过上限，满血不消耗。与金币箱区分，仍靠近自动拾取。

### 3.3 敌人、镜头与碰撞必须一起改

现有按街道前后刷怪和直接追玩家的逻辑不能原样搬入环形地图。

- 敌人依据可通行区域导航，能绕中央建筑、追过拐角，不能穿墙、卡角或永远推着车不走。先做固定地图的路点图/局部避障，暂不做通用开放世界导航。
- 刷怪点放在可读的街口/院门附近。避免玩家近距离或屏幕内凭空出现，进入前有声音或动作预告；找不到合适出生点时延后，不硬塞到玩家身边。
- 追兵从路线形成压力，不用无预警传送截断玩家。极端高压也必须留下可观察的突破选择。
- 相机不再用直街的 X 轴夹限作为整个边界；改为真实场景避障，检查环路四个朝向、墙角、院落、贴墙开火和大幅俯仰。
- 主环上初始装备能借走位拉开距离，换路能改变被夹击情况；不能只把直街弯成一个圆，所有战斗仍靠后退射击解决。

### 3.4 地图完成的证据

手机上可以连续绕主环两圈，正反方向均通过；至少两处主动改道能避开敌群；敌人能追过拐角；无强制遇到恶魔、无看不见的阻挡、无长时间寻路卡死。环路和院落均检查实体弹道与相机遮挡。

## 4. 一局节奏与撤离

先做固定关卡结构，少量随机刷怪位置；不同时做程序生成。

| 阶段 | 体验与安排 |
|---|---|
| 入场约 0–25 秒 | 低压力，可获得第一箱；让玩家练移动、转向、开火和自动拾取 |
| 第一轮交战约 25–55 秒 | 普通怪与少量跑者逼玩家绕障碍、换弹和转弯，不先制造全面包围 |
| 整理约 55–70 秒 | 明显降低新增敌人频率；现存追兵仍在，留给搜刮、恢复与选路线的机会 |
| 再交战与到站约 70–90 秒 | 引向剩余普通箱或恶魔支路；90 秒到站有声音、灯光与一次短提示 |
| 撤离窗口约 90–240 秒 | 玩家可撤离，也可继续冒险；压力分段起伏，整体随时间上升；登车期间是短而集中的最后交战 |
| 240 秒以后 | 末班车离开，沿用失控尸潮与死亡保留部分金币；明确离站反馈 |

这些时间为第一版候选。保留到站 90 秒、离站 240 秒、累计登车 5 秒作为对照；只有实际路线/试玩说明存在空等时才调整。枪声压力保留后台，但不能把喘息段完全抹平。登车期间离圈暂停进度，受伤不自动清空；既有怪计入最后交战数量，不因反复进圈无上限追加敌人。

## 5. 永久武器升级与经济

### 5.1 第一版只做一个等级轴

每把已拥有的枪从 Lv.1 到 Lv.4，花金币永久提升。等级在商店升级，进入一局时固定为该局配置；不加入经验条、局内升级三选一、零件或多槽改装。

建议首轮参数如下，全部标记为**待试玩调优**：

| 等级 | 伤害倍率 | 弹匣：步枪 / 霰弹枪 | 换弹时间倍率 | 升到本级费用 |
|---|---:|---:|---:|---:|
| Lv.1 | 1.00 | 24 / 6 | 1.00 | 免费基础级；霰弹枪仍需 240 金币买枪 |
| Lv.2 | 1.50 | 27 / 7 | 0.95 | 60 金币 |
| Lv.3 | 1.75 | 30 / 8 | 0.90 | 120 金币 |
| Lv.4 | 2.00 | 33 / 9 | 0.85 | 220 金币 |

- 伤害倍率作用于基础弹丸，霰弹每颗弹丸及远距衰减按同一倍率计算；射程、散射、射速、击退暂不升级，保持两把枪的打法差异。
- 穿甲沿用弹丸伤害；爆裂 buff 的额外爆炸伤害首版保持原值，一次扳机仍最多爆炸一次；狂热射速倍率沿用。需测试叠加后的峰值，避免升级被错误乘两次。
- 伤害、弹匣与换弹综合收益会高于单纯伤害倍率，不再沿用旧文档“改满约强 50%”承诺。
- 以步枪当前基础伤害 1、普通怪 3 血、跑者 2 血、恶魔 36 血为对照：四级对普通怪需 3/2/2/2 发，对跑者需 2/2/2/1 发，对恶魔需 36/24/21/18 发（不计 buff、落空和换弹）。让第一次升级就跨过普通怪的击杀阈值；Lv.3 主要改善持续交战与弹匣效率，不承诺每一级对每种怪都少打一枪。
- 在固定距离、命中位置、无 buff 的对照里测普通怪/跑者/恶魔的击杀用时与每匣处理量，再决定是否调整档位或敌人血量；避免用户买完一级仍完全感觉不到变化。

### 5.2 难度关系

- 基础搜刮/撤离路线允许初始装备通过；恶魔与高价值奖励可以让初始装备明显吃力，升级后更容易击败。技术熟练的玩家可提前越级挑战。
- 同一地图不按玩家装备等级自动增加敌人血量，升级后的优势要能保留下来。难度来自明确的遭遇或未来独立难度，而非暗中抵消购买收益。
- 成长不是无限加伤害；第一版 Lv.4 封顶。较强装备仍需处理跑者、绕红圈和选择换弹位置。
- 不安排“新手必死”或强制失败。失败是可以发生的学习和积累，不把付费/看广告作为通关门槛。

### 5.3 收入、购买与存档

- 暂保留普通箱 30/42/54/66/78/90、红箱 180：一局全拿共 540；撤离 100%、死亡 25% 向下取整。
- 60 金币初次升级意味着基础箱拿到 240 后死亡也可升级；带出两个低价普通箱可买首级。升级/买霰弹枪是同一钱包中的真实选择。
- 两把枪升级费用各累计 400 金币，买齐并升满合计 1,040。该奖励规模只能支撑短期试玩，不宣称已构成长期留存。
- 商店显示当前级、下一档**实际变化**、价格和余额，购买只扣一次；枪的弹匣/枪口增加小型可见部件表示升级，先不做独立资产。
- 现有钱包/已购/装备存档迁移后原值保留，已有武器默认 Lv.1；未知新版本不得静默覆盖，存储失败保留当前会话并清楚提示。
- 未购买霰弹枪的免费试用固定 Lv.1，无任何金币入账、不能升级、不更改原本装备；买过后按自己的等级正式出发。死亡不丢枪、不降级。
- 在开局锁定武器等级，子弹保存发射时的伤害配置；暂停、重开、结算和其他页面更新不能改写在途弹丸。

## 6. 引导、反馈、画面和设置

- 首次操作说明拆成开始前的极简说明与入口安全区的小提示；已看教学仍不反复弹出，暂停可主动重看操作。
- 拾取时有箱盖动作、清楚音效和物资附近短暂“+金币”；不恢复常驻物资/任务列表。
- 到站有喇叭、车灯和一次短提示，只有撤离开放且车辆离屏时显示小型方向标记；恶魔解锁时锁扣/音效变化。登车圈与车门对齐。
- 保留全身取景、自由俯仰、中心准星、真实枪口弹道，无选敌吸附。加入触控/鼠标灵敏度与音量设置并本地保存；普通视角、转角和换弹时检查遮挡、命中及落空是否可辨。
- 漫画美术不重做；弱化背景高频排线，突出主角、普通怪/跑者剪影、危险红圈、奖励和出口。青蓝仍专用于 buff。
- 先做一个修车铺/加油站地标；商店用现有模型做武器预览，结算突出收益、当前升级目标、重开入口。
- 真机检查帧率和发热，必要时提供低画质档调阴影/排线/分辨率；不以桌面模拟证明手机性能。

## 7. 数据、反馈与后端

第一轮可先用观察记录与本地事件日志；测试人数扩大后再接轻量事件收集。主动上传须说明收集内容和目的，不记录原始触控轨迹或无关个人信息。

- 记录版本、局次、地图版本、武器及等级、开始/结束、第一箱、首次受伤、恶魔交战/击败、撤离开放/进入/完成、购买升级，以及简短的手动反馈。
- 死亡位置和用时用于判断哪里阻断体验；不同枪/等级与重复开局用于区分成长收益和技术熟练。相同版本与初始条件再比较，不混用旧地图结果。
- 继续以本地存档服务试玩；账号、云存档、排行榜、防作弊、广告/支付接入后置。仅出现多设备需求或正式商业/排行要求时再设计对应后端。
- 小规模试玩只能发现问题与早期信号，不据少量样本宣称留存/付费率。口头喜欢不等于返回，金币购买也不等于付费意愿。

## 8. 实施顺序与停止扩范围的条件

| 批次 | 实际交付 | 手机验收重点 |
|---|---|---|
| **A：下一步** | 环形街区灰盒、双向通行/捷径/恶魔双出口、路点导航/出生点、地图碰撞与镜头适配；沿用现有枪与数值 | 能否主动改道、借障碍换弹？敌人是否能追而不卡？ |
| B | 阶段遭遇与喘息、恢复点、拾取/到站/登车反馈 | 无人解释能否完成一局？撤离和贪心选择是否可见？ |
| C | 两把枪 Lv.1–4、金币购买、可见升级、存档迁移与试用隔离 | 同一难关升级后是否明显更好打？是否愿意再试？ |
| D | 灵敏度/音量、武器预览、视觉辨识、设备画质与性能、必要反馈记录 | 真实手机能否连续玩两三局？能否说清改动改善了什么？ |
| E | 固定版本，邀请约 5–10 位目标玩家，观察开始/退出/重开和隔天自主返回 | 哪些体验被主动重复？哪些步骤仍阻碍理解或操作？ |

A 先完成可绕行的战场，不等待升级和美术一起交付；验收通过再推进 B/C。每批次独立提交、PR、检查后合并。技术回归之外必须保留 Patrick 手机试玩，不能用机器人胜率代替乐趣结论。

邀请前的底线：能自行开始、搜箱、辨认敌人、看懂撤离并结算；无严重碰撞/视角/输入阻断，至少一次真机性能验证。到达底线即邀请，轻微表现问题进入反馈清单，不再因“再补一个系统”延后测试。

本轮不做：新武器/新怪/投掷道具、更多地图、随机生成、完整安全屋、幸存者、漫画分享、每日排行、账号与商业 SDK。它们保留为远期候选，不承诺做完再找玩家。
